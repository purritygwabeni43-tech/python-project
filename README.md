# Python Project README

## Interactive Python Mini Program

This project is a beginner-friendly Python application that demonstrates the use of:

* Functions
* Loops
* Conditional statements
* Lists
* Operators
* Modules (`math` and `random`)
* User input
* Type casting
* Function arguments and return values

The program provides users with three interactive features through a menu-driven system.

---

# Features

## 1. Simple Quiz

A short quiz that:

* Checks user answers
* Uses conditional statements
* Calculates scores
* Demonstrates logical and comparison operators

### Quiz Questions Include:

* Fruit identification
* Number of provinces in South Africa

---

## 2. Daily Motivation Generator

A motivational message generator based on the day of the week.

### Concepts Used:

* Lists
* Loops (`for`)
* Boolean variables
* `break` statement
* String comparison

---

## 3. Even or Odd Checker

Checks whether a number is even or odd.

### Additional Features:

* Calculates square root using the `math` module
* Squares a number using a function passed as an argument

---

# Technologies Used

* Python 3
* Built-in Python modules:

  * `math`
  * `random`

---

# Program Structure

## Functions Included

| Function                 | Purpose                                     |
| ------------------------ | ------------------------------------------- |
| `line()`                 | Prints a separator line                     |
| `check_answer()`         | Checks quiz answers                         |
| `execute_function()`     | Demonstrates passing functions as arguments |
| `square_number()`        | Squares a number                            |
| `simple_quiz()`          | Runs the quiz section                       |
| `motivation_generator()` | Displays motivational messages              |
| `even_or_odd()`          | Checks even/odd and performs calculations   |

---

# How to Run the Program

1. Install Python 3 on your computer.
2. Save the code as `main.py`
3. Open a terminal or command prompt.
4. Run the program using:

```bash
python main.py
```
